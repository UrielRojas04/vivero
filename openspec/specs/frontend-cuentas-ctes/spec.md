## Requirements
### Requirement: Visualización de Cuentas Corrientes
La interfaz MUST adaptar sus vistas de Clientes para que el usuario pueda consultar de forma inmediata los saldos tanto en dinero como en bandejas retornables para cada cliente.

#### Scenario: Visualización de indicadores de deuda o crédito
- **WHEN** el usuario visualiza la lista de clientes (ya sea en desktop o mobile)
- **THEN** el sistema renderiza etiquetas visuales claras (con colores de advertencia/éxito) para informar de un vistazo si el cliente tiene deudas o saldo a favor, o deuda de bandejas.
