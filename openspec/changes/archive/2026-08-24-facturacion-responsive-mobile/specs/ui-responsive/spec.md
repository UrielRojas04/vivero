## ADDED Requirements

### Requirement: Listado de Facturas Responsivo
The system SHALL present the invoice list page (`FacturasPage`) properly aligned and structured on mobile screens, avoiding overlap between table rows and floating action buttons.

#### Scenario: Mobile viewport viewing
- **WHEN** the user accesses the invoice list on a mobile device
- **THEN** the table is horizontally scrollable, and the row content remains fully visible without breaking the application width limit.
